# Скрипт аудита сервера (VPS Ubuntu)

Скрипт `audit_server.py` предназначен для комплексной диагностики серверного окружения на VPS Ubuntu (`/var/www/legalyze`).

## Что проверяет скрипт:
1. **Система и ресурсы:** Версия ОС, ядро, доступная оперативная память (RAM), свободное место на диске.
2. **Сеть и безопасность:** Слушающие порты (80, 443, 3000, 5432 и др.), статус UFW Firewall.
3. **Nginx:** Статус службы, синтаксический тест `nginx -t`, активные конфигурационные файлы в `/etc/nginx/sites-enabled/` и `/etc/nginx/conf.d/`.
4. **SSL / HTTPS:** Сертификаты Certbot / Let's Encrypt и каталоги `/etc/letsencrypt/live/`.
5. **Процессы:** Запущенные процессы Node.js, Next.js, PM2, Docker, PostgreSQL, systemd-сервисы.
6. **Проект `/var/www/legalyze`:** Наличие сборки `.next`, `package.json`, структура `data/updates/` и маскированная проверка переменных окружения `.env`.
7. **Логи Nginx:** Последние ошибки из `/var/log/nginx/error.log`.

---

## Как запустить на сервере:

### Способ 1: Быстрый запуск одной командой через SSH
```bash
python3 /var/www/legalyze/audit_server.py
```
*(или скопируйте `audit_server.py` в любую папку на сервере и запустите `python3 audit_server.py`)*

### Способ 2: Сохранение и просмотр отчета
Скрипт выведет полный отчет в консоль и автоматически сохранит его в файл `server_audit_report.txt`:
```bash
cat server_audit_report.txt
```
Скопируйте вывод этого отчета и отправьте сюда для детального анализа и рекомендаций по настройке.
